### Task 2 — `detect-web.sh` (green: web-detection pura)

**Files:**
- Create: `~/.claude/skills/web-e2e-test/scripts/detect-web.sh` (executable, bash 3.2, ~50 righe)

**Red phase:** lo script non esiste; il suo smoke test (T4#10-14) non può ancora passare.

**Green phase — logica (da spec §3, cascata fail-safe verso non-web):**
1. Arg `ROOT="${1:-$PWD}"`. `set -u`.
2. **Cascata** (primo che decide vince), stampa su stdout una riga `web` | `non-web`, e se
   `web` una seconda riga `signal=<...>`:
   - `[ -f "$ROOT/.claude/web-e2e.yaml" ]` e `grep -Eq '^web:[[:space:]]*false' web-e2e.yaml`
     → `non-web` (override esplicito). Se `^web:[[:space:]]*true` → `web` (`signal=yaml`).
   - `[ -f "$ROOT/package.json" ]` e
     `grep -Eq '"(dev|start|serve)"[[:space:]]*:' package.json` **o**
     `grep -Eq '"(vite|next|react-scripts|@angular/cli|vue|svelte|astro|nuxt|remix|webpack-dev-server)"' package.json`
     → `web` (`signal=package.json`).
   - `index.html` in `$ROOT`, `$ROOT/public`, `$ROOT/src`, `$ROOT/dist` (`[ -f ]` su ciascuno)
     → `web` (`signal=index.html`).
   - else → `non-web`.
3. Exit 0 sempre (la classificazione è nello stdout, non nell'exit code; più facile da testare).

Bash 3.2-clean (`grep -Eq`, `[ -f ]`, `case`/`if`, niente assoc array). `chmod +x`.
